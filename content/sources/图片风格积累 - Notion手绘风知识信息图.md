# Notion 手绘风知识信息图 / 白板式系统架构海报 / 轻量漫画风流程图

这类图不是严肃的企业架构图，也不是科技感 UI 图，而是把复杂系统拆成「手绘模块卡片」的可视化说明图，强调清晰、亲和、结构化、易传播。

## 一句话风格描述

浅色纸张背景上的手绘知识卡片信息图，用圆角彩色模块、黑色马克笔线条、简笔人物、箭头流程和红色重点下划线，把复杂系统设计讲成一张轻松易懂的白板式架构图。

## 风格定位

它的视觉目标不是“酷”，而是让读者觉得：

> 这套系统很复杂，但我好像能看懂。

更具体地说，这是一种：

- 手绘感
- 知识卡片感
- 白板讲解感
- Notion / 小红书知识图风
- 轻松但有结构
- 专业内容的低门槛表达

## 画面结构

典型布局是模块化信息图：

- 顶部大标题
- 副标题说明主题
- 中间 6 个左右核心模块卡片
- 底部一条流程总览
- 模块之间用箭头串联
- 每个模块带编号，如 `#01`、`#02`、`#03`
- 每块内容都带小图标、小人物或小流程

这套结构适合解释：

- 系统架构
- 工作流
- 方法论
- AI Agent 流程
- 产品机制
- 内容生产管线
- 研究框架

## 线条风格

线条是明显的手绘马克笔风：

- 黑色粗线轮廓
- 线条略微不规则
- 圆角矩形边框
- 手绘箭头
- 手绘下划线
- 小星星、小波浪线、小装饰符号
- 简笔图标和人物

这种线条的作用不是装饰，而是降低技术内容的距离感和理解门槛。

## 色彩风格

配色是低饱和马卡龙色块加米白纸张背景：

- 背景：暖米白 / 纸张底色
- 模块：浅蓝、浅绿、浅紫、浅橙
- 强调色：珊瑚红 / 橙红色下划线
- 文字：黑色为主
- 少量阴影和柔和渐变

整体要柔和、不刺眼，适合知识类内容传播。

## 字体与文字风格

字体气质接近手写黑体 / 手绘标题字：

- 大标题很粗，像手写板书
- 小标题带编号
- 关键词用红色下划线强调
- 英文和中文可以混排
- 文字密度可以偏高，但要通过卡片切分避免压迫感

它非常适合公众号、小红书、知识卡片、课程封面这类场景。

## 图形元素

常用的是低复杂度、可快速识别的符号：

- 简笔人物
- 文件图标
- 文件夹
- 仪表盘
- 天平
- 箭头
- 管道式流程
- 放大镜
- 工厂 / 实现模块
- 审核 / 评分 / 记录符号

这些元素的作用是把抽象概念具象化。

## 适用边界

适合：

- 解释复杂系统
- 拆解工作流
- 展示方法论
- 说明多模块协作关系
- 做可传播的知识海报

不适合：

- 严肃企业汇报里的正式架构图
- 强科技感、强未来感视觉
- 需要精密工程感的技术示意图
- 逼真写实插画或产品 UI 展示图


## 负向约束

如果要稳定生成同款图，可以额外加上这些限制：

- 不要真实照片
- 不要 3D 渲染
- 不要强科技蓝光效
- 不要深色赛博背景
- 不要复杂 UI 界面截图感
- 不要过度写实人物
- 不要企业 PPT 风
- 不要冷冰冰的正式架构图
