# Memory Candidates

这个文件是经验候选池，不是正式规则库。这里的内容默认不被 agent 自动加载，也不代表已经成为项目约定。

用途：降低捕获经验的门槛，同时避免把一次性交互、临时偏好、未经验证的判断直接写进 `AGENTS.md`、`WIKI.md` 或 Skill。

## 使用规则

- 新经验先进入这里观察，不直接制度化。
- 候选经验必须说明它会如何改变下一次行动。
- 每条候选经验定期分流为：观察、进 `AGENTS.md`、进 `WIKI.md`、做 Skill、丢弃。
- 如果一条经验说不清下次会改变什么行为，优先丢弃。

## 晋升门槛

满足以下任一条件，才考虑升级为正式资产：

- 出现 3 次以上。
- 虽然只出现 1 次，但漏掉代价很高。
- 能明确改变下一次 agent 行为。
- 不依赖某次临时上下文。

## 分流标准

- 稳定判断、所有任务都该知道 -> `AGENTS.md`
- wiki 写作或整理原则 -> `WIKI.md`
- 有明确触发场景且包含 3 步以上动作 -> Skill
- 正例、反例、拒绝理由 -> taste 案例，放入相关 wiki 页或 `WIKI.md`
- 一次性偏好、临时纠错、低复用细节 -> 丢弃
