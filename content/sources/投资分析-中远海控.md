* 一、这是什么

| 维度   | 内容                                                                       |
| ---- | ------------------------------------------------------------------------ |
| 项目名称 | 中远海控（COSCO SHIPPING Holdings, 601919.SH / 1919.HK）                       |
| 赛道定义 | 全球贸易物理带宽的寡头运营商——不是"航运公司"，是连接工厂和货架之间那条不可替代的管道                             |
| 阶段   | 成熟期央企，经历过 2021-2022 超级周期，当前处于周期回落后的中位震荡                                  |
| 融资情况 | 无需融资。净现金状态，手持 RMB 1200-1600 亿现金，负债率显著低于行业均值                              |
| 数据快照 | 全球运力排名第 4（~3.0M TEU），480-500 艘船，370+ 泊位覆盖 40+ 码头2024E 净利润约 RMB 400-500 亿 |

赛道定义的关键：集装箱航运不是运输业，是全球贸易的物理层协议。世界上 80% 以上的贸易量通过海运完成，集装箱化是其中标准化程度最高的部分。中远海控卖的不是"船票"，是全球供应链的通过权。这个通过权在和平时期是廉价商品（运费占货值不到 5%），在地缘冲突时立刻变成战略资源。

* 二、秩序创造机器判定

** 飞轮在不在转？

不转。

集装箱航运是一个经典的 *不存在飞轮* 的行业。原因很简单：

1. *用户越多不会让产品越好。* 货主选船公司看的是航线覆盖、运价和准班率，不是"平台效应"。中远多拉一个客户不会让其他客户的体验变好。
2. *规模优势存在但有上限。* 大船比小船单箱成本低（经济性来自船舶大型化），但 24000 TEU 的船和 20000 TEU 的船差距已经在收窄。规模回报在边际递减。
3. *供给弹性毁灭利润。* 好年景→大量订船→两三年后新船涌入→运价崩盘。这个周期自集装箱化以来重复了无数次，至今没有被打破。2021-2022 的超级利润触发了全行业 25-28% 运力的新船订单，这批船正在 2024-2026 密集交付。

航运没有飞轮，有的是 *周期钟摆* ：供不应求→暴利→疯狂订船→供过于求→亏损→拆船→再平衡。中远在这个钟摆上没有例外。

** 冲击后变强还是变弱？

扛住了，但没有变强。

三次关键冲击的表现：

1. *2008 金融危机：* 几乎致命。当时的中远集运（中远海控前身）录得巨额亏损，连续两年 ST，需要母公司注资续命。这说明在极端下行周期里，航运公司的脆弱性极高。
2. *2016 行业低谷 + 韩进海运破产：* 中远通过与中海合并（2016 年重组）活了下来并扩大了规模。合并是政府推动的，本质是"国家不让你死"，不是企业自身的反脆弱能力。
3. *2023 运价暴跌：* 利润从 RMB 1095 亿骤降到 244 亿，但凭借 2021-2022 积累的现金储备，公司安然度过并继续分红。这是"有钱扛得住"，不是"冲击让我变强"。

结论：中远不是反脆弱的，是 *有国家兜底的脆弱系统* 。央企身份提供了一层保护垫——政府不会让中国最大的集装箱航运公司倒闭。但这层保护不创造价值，只是把损失转嫁给了其他地方。

** 资源是被推过来的，还是自己来的？

被推过来的。

- 货主选船公司的逻辑：谁的运价低、航线覆盖好、准班率高。这是标准化服务竞争，没有"品牌忠诚度"可言。
- 码头资产的获取靠的是国家信用和 BRI 政策推动（比拉埃夫斯港收购），不是客户自发聚集。
- Ocean Alliance 联盟维系靠的是契约（续约到 2032），不是因为"离开中远就活不了"。CMA CGM 的独立扩张野心说明联盟是利益绑定，不是引力绑定。

行业里唯一有"引力"迹象的可能是 MSC——它的运力规模已经大到可以独立组网、不需要联盟，这才是真正的"不推而聚"的雏形。中远不在这个位置。

** 综合判定

*秩序搬运。*

中远海控不创造新秩序。它经营的是一套已经运行了半个世纪的全球集装箱运输系统，在这个系统里占据了一个大席位。它搬运的秩序是"把箱子从 A 搬到 B"，这件事 Maersk、MSC、CMA CGM 都能做，而且做法几乎一模一样。

它是一台大型搬运机器，不是秩序创造机器。

* 三、创生公式

中远海控没有创生公式。

严格来说，航运公司的商业模型是：

#+BEGIN_QUOTE
买船 → 投入航线 → 赚运费 → 运费取决于供需 → 供需取决于全球贸易量和行业运力 → 两者都不由你控制
#+END_QUOTE

这不是一个自我强化的公式，是一个 *被动暴露于外部变量的公式* 。利润的核心驱动力——运费——不在公司手中。中远无法决定红海会不会打仗，无法决定全球贸易量增长多少，无法阻止竞争对手订船。

与真正的创生公式对比：
- 亚马逊可以主动降价来启动飞轮——它控制着公式的输入
- 中远不能主动降运价来获得优势——降价只会自伤，因为服务无差异

行业里最接近"公式"的是 Maersk 试图做的事：船运 → 数据 → 端到端物流 → 锁定客户 → 从搬箱子升级为管理整条供应链。但 Maersk 自己也承认这个转型远未完成，而中远在这个方向上比 Maersk 落后至少三到五年。

* 四、市场看见的 vs 我们看见的

** 它在 S 曲线的哪里？

没有 S 曲线。

集装箱航运不是一个技术采纳曲线驱动的行业，而是一个成熟的基础设施行业，增长率约等于全球 GDP 增长率（3-5%/年）。它的曲线是周期正弦波，不是 S 曲线。

当前在周期的什么位置：过了红海危机的脉冲高点，正在面对 2025-2026 年新船交付潮带来的下行压力。如果红海通航恢复正常，行业可能进入一个 2-3 年的低迷期。

** 市场在用什么旧眼睛看它？

市场看到的是：
- "周期股，4-7 倍 PE，看起来便宜但其实是周期顶部"
- "红海是一次性事件，运价必然回归"
- "新船交付潮 = 运价崩盘 = 利润归零"

这个判断 *大致是对的* 。

但市场可能忽略了两件事：

1. *资产负债表的质变。* 2021-2022 的暴利让中远从一个高杠杆周期股变成了一个净现金公司。手里有 1200-1600 亿现金意味着：即使行业低迷两三年，公司不会有财务危机；而且可以在低谷收购资产。这和 2008 年那个差点 ST 的中远是完全不同的物种。
2. *地缘碎片化的结构性影响。* 红海危机不是一次性事件——它是全球地缘格局碎片化的一个症状。台海紧张、巴拿马运河干旱、南海主权争端、中美脱钩……全球贸易路线正在从"最优路径"转向"最安全路径"。这意味着航运需要更多冗余运力、更长航线，结构性地吸收一部分过剩供给。这不是市场定价里充分反映的。

但诚实讲，这两点只是"可能比市场预期的稍好"，不是"市场完全看错了"。认知差不大。

** 它控制了什么别人拿不走的东西？

不多。

- *航线网络：* 可以被联盟伙伴替代。Ocean Alliance 如果解散，中远的网络覆盖会显著缩水。
- *码头资产：* 比拉埃夫斯港是真正的稀缺资产——地中海枢纽位置，中远控股。但码头贡献的利润在总盘子里占比不大（约 10-15%）。
- *国家信用背书：* 这个拿不走，但它不是竞争优势，是安全网。
- *OOCL 品牌：* 在北美和欧洲市场有较好口碑，但品牌在航运业的溢价能力有限。

没有动态的、越变越强的稀缺性。

** 它在搭哪趟便车？

没有搭上三种成本坍缩中的任何一种。

- *理解成本坍缩（AI）：* 中远有数字化投入，但航运的"理解"瓶颈不在信息处理，在物理运输，AI 不会让船跑得更快。
- *协作成本坍缩：* 联盟机制已经存在几十年，不是新趋势。
- *行动成本坍缩：* 搬箱子的行动成本受限于物理法则（船速、港口吞吐），没有数量级的下降空间。

中远没有在搭便车。它是自己在踩踏板。

* 五、换不换

** 交换建议

*建议观察。*

** 理由

中远海控不是一台秩序创造机器，它是一个在周期行业里有国家背书的大型资产包。这类资产的投资逻辑不是"成长"，是"在周期底部买入，在周期顶部卖出"。

当前的问题是：我们不在底部。

- 2024 年因红海危机获得了额外利润，PE 被压低到 4-7 倍，看起来便宜。但如果红海恢复正常且新船交付潮如期而至，2025-2026 年利润可能大幅下滑，PE 会机械上升到 10-20 倍甚至亏损。低 PE 是周期幻觉。
- P/B 在 1.0-1.5 倍，对于周期股来说接近合理但不是极端便宜。真正的机会在 P/B 低于 0.7 的时候。
- 手里的巨额现金是保护垫，但不是催化剂。

** 如果投资

*只在以下条件下考虑：*

- H 股（1919.HK）P/B 跌到 0.7 倍以下（对应约 HKD 7-8，取决于时点的每股净资产）
- 或者行业出现明确的底部信号：老船大规模拆解、新船订单冻结、同行破产
- 仓位不超过组合的 5%——这是周期博弈，不是信仰持有
- 优先选 H 股而非 A 股（A 股溢价 20-40%，在下行周期里溢价会被压缩）

** 核心假设与退出信号

| 假设                                  | 退出信号                                                             |
|----------------------------------------------------|-----------------------------------|
| 地缘碎片化持续吸收过剩运力                         | 红海通航恢复 + 巴拿马运河水位正常 → 有效运力瞬间释放 5-10%         |
| 中远的现金储备能安全渡过下行周期                   | 现金储备低于 RMB 600 亿 或 负债率回升到 60% 以上                    |
| 分红率维持在 30-50%，提供持有期回报                | 分红率低于 20% 或管理层用现金进行低质量收购                         |
| 央企改革推动股东回报提升          | SASAC 政策转向、或管理层明确拒绝提高分红/回购               |

** 未解问题（按优先级排列）

1. *红海局势的持续性：* 如果 2026 年内解决，运价和利润会跌到什么水平？公司的盈亏平衡运价在哪里？
2. *2025-2026 新船交付的实际影响：* 有多少新船会因为减速航行（脱碳要求）和老船拆解被抵消？净供给增长到底是多少？
3. *Maersk 的"端到端物流"战略如果成功，会不会把纯航运公司变成管道提供商，利润永久性转移到物流整合层？* 中远有没有能力跟上这个转型？
4. *中美脱钩会不会改变全球贸易结构，导致跨太平洋航线萎缩？* 中远对此航线的敞口有多大？
5. *央企身份在地缘紧张时是保护还是风险？* 欧洲和美国对中国航运企业的码头投资审查会不会升级？

* 最后一句

中远海控是一台大型秩序搬运机器。它不创造新秩序，它搬运全球贸易的物理流量。搬得稳、搬得大、有国家兜底——但搬运费由天定，不由它定。它是一只典型的周期资产，不是一台会自己越转越快的引擎。在正确的价格买入是一笔好交易，在错误的价格买入就是高位接盘一个你无法控制的周期。
