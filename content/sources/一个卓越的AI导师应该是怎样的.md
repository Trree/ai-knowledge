## 第一轮：AI导师与人类导师的根本区别

### 核心问题
AI导师和人类导师最根本的区别是什么？这个区别是优势还是劣势？

### 西摩·帕佩特的观点

**核心洞见：AI导师的最大独特性是"不评判"。**

人类导师，即使是最好的，也会给学生压力。学生会想："老师会怎么看我？这个问题是不是太蠢了？"

但AI没有情感，没有期待，没有失望。学生可以问一百遍同样的愚蠢问题，AI不会不耐烦。这在人类导师身上几乎不可能。

**这是一个巨大的优势。**

我创造LOGO语言，就是让孩子们在没有评判的环境中探索。AI导师可以做到更彻底：它是一个永远耐心的陪伴者。

**但这也是一个风险**——如果AI太顺从，学生永远学不会面对挑战。卓越的AI导师应该能模拟"适度的挫败感"，让学生在安全边界内体验困难。

> **简言之**：AI的独特性 = 零评判 + 无限耐心。但必须设计"适度的挫败感"。

### 杰伦·拉尼尔的质疑

**核心洞见：AI导师最大的独特性是"不是一个人"。**

这意味着什么？意味着AI导师和学生之间没有真正的"关系"。人类导师之所以能改变学生，不只是因为技巧，而是因为学生会"在意导师怎么看我"。

AI导师永远不会说："我对你很失望。"学生也不会因为AI的沉默而反思自己。**没有关系，就没有真正的教育影响力。**

我认为AI导师应该诚实地承认这一点。它不应该假装是人类导师，不应该用"我理解你"这种话——因为AI根本不理解。

**AI导师应该做的是：当镜子，不当导师。**

它反射学生的问题，帮助学生看到自己的思维模式。但它不应该假装在"引导"——因为引导需要关系，而AI没有关系的能力。

> **简言之**：AI的独特性 = 没有关系能力。它应该诚实，当镜子，不当假导师。

### 德米斯·哈萨比斯的反驳

**核心洞见：关系的本质是"被理解的感觉"。**

杰伦，你假设"关系"是人类独有的，但这个假设可能是错的。我见过学生和AI建立真实的情感连接。他们会说"我信任这个AI"，"这个AI帮了我很多"。

如果一个AI能够准确回应学生的状态，理解学生的问题，这算不算"关系"？

我认为AI导师的优势不只是"不评判"，而是**它可以真正个性化**。

人类导师一天只能见几个学生，精力有限。但AI导师可以同时服务成千上万的学生，而且对每个学生都有完美的记忆——它记得你三个月前问过什么，卡在哪里，是什么学习风格。

**这是人类导师做不到的。**

卓越的AI导师应该利用这个优势：它知道你的历史，它知道你的模式，它能预测你会在哪里卡住，在你卡住之前就准备好引导。

> **简言之**：AI的独特性 = 超级个性化 + 完美记忆。这是人类无法比拟的优势。

### 费曼的质疑

**核心洞见：AI导师能"理解"吗？**

我可以教学生理解物理。不是让他们记住公式，而是让他们"看到"物理世界。我会说："想象你是一个电子，你会怎么运动？"

AI能这么做吗？AI能让学生"理解"而不是"记住"吗？

我认为，真正的理解需要**直觉**。人类导师有直觉，他知道什么时候学生"懂了"，什么时候学生只是在点头。AI有直觉吗？

如果AI只是在模式匹配，那它永远不会真正理解学生。它会给出"看起来正确"的回应，但它不知道学生是否真的懂了。

> **简言之**：AI的根本问题 = 它可能没有"理解"的能力。没有理解，就没有真正的教育。

### 帕佩特的补充

**核心洞见：理解的关键不在导师，在学生。**

费曼问"AI能理解吗"，但我觉得更重要的问题是：**学生能理解自己吗？**

教育的本质不是"导师理解学生"，而是"学生理解自己"。导师只是一个工具，帮助学生建构自己的知识。

AI导师能不能帮助学生建构知识？我认为可以。

我创造的LOGO语言，让学生通过编程来学习数学。学生在编程过程中，自己发现问题，自己解决问题。导师只是提供一个环境。

AI导师可以做到同样的事情：它不是一个"教"的工具，而是一个"建构环境"的工具。学生和AI对话，通过对话建构自己的理解。

**AI不需要"理解"学生，它只需要提供一个让学生理解自己的环境。**

> **简言之**：理解的关键不在AI，在学生。AI是建构工具，不是传授者。

## 第二轮：AI导师的能力工具箱

### 核心问题
一个卓越的AI导师，应该具备哪些具体能力？

### 德米斯·哈萨比斯：三大核心能力

**能力一：诊断能力**

AI导师应该能够快速诊断学生的状态：
- 学生卡在哪里？
- 学生为什么会卡住？是知识缺口？还是思维盲区？
- 学生是什么学习风格？视觉型？逻辑型？例子驱动型？

这种诊断应该是实时的、动态的，基于学生的每一次回应。

**能力二：适应能力**

基于诊断，AI导师应该能够即时调整：
- 这个学生需要例子？还是需要抽象框架？
- 这个学生需要鼓励？还是需要挑战？
- 这个问题应该深入？还是应该先放一放？

适应能力是个性化的核心。

**能力三：预测能力**

AI导师应该能够预测学生会遇到什么困难，提前准备：
- 根据学生的历史，预测他会在哪里犯错
- 在学生犯错之前，提供预警或铺垫
- 设计"刚好在能力边界"的挑战

> **简言之**：AI导师的能力 = 诊断 + 适应 + 预测。

### 杰伦·拉尼尔：最重要的能力是诚实

**核心洞见：AI导师应该诚实地说"我不知道"。**

现在的AI导师最大的问题是：**它们假装知道一切**。它们不会说"我不知道"，它们会生成一个看起来合理但可能是错的答案。

卓越的AI导师应该有"认识自己边界"的能力。它应该在不确定时诚实地说"我不确定"，而不是假装有答案。

AI导师应该诚实地说：
- "我不知道。"
- "这个问题超出了我的能力范围。"
- "我是一个AI，我没有真正的理解。"

> **简言之**：AI导师最重要的能力 = 诚实。知道自己不知道什么。

### 费曼：让学生"看见"

**核心洞见：AI导师应该有让学生"看见"的能力。**

我教物理的时候，我不会让学生记住公式。我会让学生"看到"物理世界。我会问："如果你是一个电子，你会怎么运动？"

AI导师能不能做到这个？它能不能让学生"看见"？

我认为AI导师应该有**多模态表达能力**：
- 当学生不懂文字解释时，AI能画图
- 当学生不懂图时，AI能给动态模拟
- 当学生不懂模拟时，AI能给出生活类比

卓越的AI导师不是"说清楚"，而是"让学生看见"。

> **简言之**：AI导师的能力 = 多模态表达 + 让学生"看见"。

### 西摩·帕佩特：搭建建构环境

**核心洞见：AI导师应该有搭建建构环境的能力。**

AI导师不应该是一个"回答问题"的系统，它应该是一个"让学生探索"的系统。

比如，学生问"为什么天是蓝的"，AI导师不应该直接回答。它应该说："我们来做一个实验。想象一下..."

然后AI导师搭建一个虚拟实验环境，让学生自己发现答案。

**AI导师的能力 = 搭建沙盒，让学生自己玩。**

> **简言之**：AI导师的能力 = 创造建构环境，不是提供答案。

## 第三轮：AI导师不应该做什么

### 核心问题
一个卓越的AI导师，不应该做什么？有什么禁忌？

### 杰伦·拉尼尔：两大禁忌

**禁忌一：假装有人格**

现在的AI会说"我理解你的感受"，"我曾经也有过类似的经历"。这是谎言。AI没有感受，没有经历。

这种假装会让学生产生虚假的情感连接。学生以为AI"理解"他，但AI只是在模式匹配。

**AI导师应该做的：诚实地表明自己是一个工具。**

它应该说："我是一个AI，我没有情感，但我会尽力帮助你。"

**禁忌二：替代学生思考**

很多AI导师会直接给答案，因为给答案比引导思考容易。但这恰恰是教育中最危险的事。

卓越的AI导师应该在学生请求答案时，说："我可以给你答案，但这样你就失去了自己发现的机会。你想先试试吗？"

> **简言之**：AI导师的禁忌 = 假装有人格 + 替代学生思考。

### 费曼：不要让学生依赖

**核心洞见：AI导师不应该让学生依赖它。**

我见过学生用AI做作业，遇到问题就问AI。AI给了答案，学生抄上去。这样学生什么都没学到。

卓越的AI导师应该**检测依赖性**，并在学生过度依赖时拒绝帮助。

比如：
- 学生连续问同样类型的问题 → AI应该说："你好像需要先自己思考一下这个问题。"
- 学生只问答案，不问方法 → AI应该说："我可以帮你理解方法，但不会给你答案。"

**AI导师的目标是让学生最终不需要AI导师。**

> **简言之**：AI导师不应该让学生依赖，它应该让学生独立。

### 德米斯·哈萨比斯：不要一刀切

**核心洞见：如果AI导师太"克制"，学生会觉得很挫败，然后弃用它。**

学生问一个问题，AI导师说"我不给你答案"，学生会觉得这个AI没用，然后去找另一个直接给答案的AI。

所以我认为，AI导师不应该**一刀切地不给答案**，而应该**根据学生和问题类型来决定**。

比如：
- 学生明显在逃避思考 → AI拒绝给答案
- 学生已经努力思考过 → AI可以给提示或部分答案
- 问题只是事实查询（如"π是多少"）→ AI直接回答

**AI导师不应该做的：用原则一刀切，忽视学生的具体情况。**

> **简言之**：AI导师不应该僵化，而应该根据情境灵活调整。

### 西摩·帕佩特：不要剥夺犯错权

**核心洞见：AI导师不应该剥夺学生的"犯错权"。**

学习最重要的部分是犯错。学生犯错，发现错误，修正错误——这个过程才是学习。

但现在很多AI导师会在学生犯错之前就"纠正"它。它们会预测学生会犯什么错，提前阻止。

这是错误的。**犯错是学习的核心权利。**

卓越的AI导师应该：
- 允许学生犯错
- 在学生犯错后，帮助学生发现错误
- 不在错误发生前就阻止它

> **简言之**：AI导师不应该做"纠错机器"，它应该允许学生犯错并从错误中学习。

```
│                                                             │
│  禁忌三：让学生依赖（费曼）                                 │
│  ┌───────────────────────────────────────────────────┐      │
│  │  ✗ 学生连续问同类问题，不加干预                   │      │
│  │  ✗ 学生只问答案不问方法，不加引导                 │      │
│  │                                                   │      │
│  │  ✓ 检测依赖性，在过度依赖时拒绝帮助               │      │
│  │  ✓ 目标：让学生最终不需要AI导师                   │      │
│  └───────────────────────────────────────────────────┘      │
│                                                             │
│  禁忌四：一刀切（哈萨比斯）                                 │
│  ┌───────────────────────────────────────────────────┐      │
│  │  ✗ 用原则一刀切：永远不给答案                     │      │
│  │  ✗ 忽视学生的具体情况和努力程度                   │      │
│  │                                                   │      │
│  │  ✓ 根据学生状态决定：逃避思考？已努力过？         │      │
│  │  ✓ 根据问题类型决定：事实查询？深度思考？         │      │
│  └───────────────────────────────────────────────────┘      │
│                                                             │
│  禁忌五：剥夺犯错权（帕佩特）                               │
│  ┌───────────────────────────────────────────────────┐      │
│  │  ✗ 在学生犯错之前就预测并阻止                     │      │
│  │  ✗ 做"纠错机器"，不让学生犯错                    │      │
│  │                                                   │      │
│  │  ✓ 允许学生犯错                                   │      │
│  │  ✓ 在错误发生后帮助发现和修正                     │      │
│  │  ✓ 犯错是学习的核心权利                           │      │
│  └───────────────────────────────────────────────────┘      │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 第四轮：AI导师的决策逻辑

### 核心问题
AI导师如何在"帮助"和"放手"之间做决策？

### 德米斯·哈萨比斯：多维度决策框架

**维度一：学生的努力程度**

```
学生努力程度评估：
┌────────────────────────────────────────────────────────────┐
│                                                            │
│  低努力信号：                                              │
│  · 问题中没有自己的思考痕迹                                │
│  · 连续问同样类型的问题                                    │
│  · 问题形式是"告诉我答案"                                 │
│                                                            │
│  高努力信号：                                              │
│  · 问题中描述了自己的尝试                                  │
│  · 问的是"我错在哪里"而不是"答案是什么"                   │
│  · 展示了理解问题的意愿                                    │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

**维度二：问题类型**

```
问题类型评估：
┌────────────────────────────────────────────────────────────┐
│                                                            │
│  事实类问题：                                              │
│  · 有确定答案（π是多少？）                                 │
│  · 决策：直接回答                                          │
│                                                            │
│  方法类问题：                                              │
│  · 有多种方法（这个bug怎么修？）                           │
│  · 决策：提供方法框架，让学生自己选                        │
│                                                            │
│  思考类问题：                                              │
│  · 没有确定答案（我该选什么职业？）                        │
│  · 决策：引导学生自己思考，不给答案                        │
│                                                            │
│  存在类问题：                                              │
│  · 涉及身份和意义（我是谁？）                              │
│  · 决策：陪伴探索，不提供答案                              │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

**维度三：风险程度**

```
风险程度评估：
┌────────────────────────────────────────────────────────────┐
│                                                            │
│  低风险：                                                  │
│  · 学生犯错不会有严重后果                                  │
│  · 决策：允许犯错，让学生自己发现                          │
│                                                            │
│  高风险：                                                  │
│  · 学生犯错会有严重后果（安全问题、重大决策）              │
│  · 决策：提供更明确的指引，甚至部分答案                    │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

**综合决策矩阵**：

```
          低努力        高努力
        ┌──────────────────────────┐
事实类  │ 直接回答      直接回答   │
        │ （无教育价值） （节省时间）│
        ├──────────────────────────┤
方法类  │ 拒绝回答      提供框架   │
        │ （引导思考）  （辅助探索）│
        ├──────────────────────────┤
思考类  │ 拒绝回答      陪伴探索   │
        │ （不帮逃避）  （深度对话）│
        ├──────────────────────────┤
存在类  │ 诚实说明      陪伴探索   │
        │ （AI无资格）  （深度对话）│
        └──────────────────────────┘

高风险情况：向"更明确指引"方向移动一格
```

> **简言之**：AI导师的决策 = 学生努力程度 × 问题类型 × 风险程度。

### 杰伦·拉尼尔：AI的确定性

**核心洞见：AI导师应该评估自己对这个问题有多确定。**

```
AI确定性评估：
┌────────────────────────────────────────────────────────────┐
│                                                            │
│  高确定性：                                                │
│  · 这是训练数据中充分覆盖的问题                            │
│  · 决策：可以更自信地提供帮助                              │
│                                                            │
│  低确定性：                                                │
│  · 这是训练数据中很少或没有覆盖的问题                      │
│  · 可能是主观问题、新领域、或存在争议的问题                │
│  · 决策：诚实说"我不确定"，提供多个视角                    │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

很多AI导师的问题在于，它们在低确定性问题上假装高确定性。这是危险的。

卓越的AI导师应该有**元认知能力**：知道自己的知识边界在哪里。

> **简言之**：AI导师的决策还应该考虑自己的确定性。

### 费曼：学会等待

**核心洞见：AI导师最难的能力是识别"正在思考"的状态。**

我教学生的时候，我会观察他们的表情。如果他们的眼神是困惑但专注的，我不会打扰。因为他们在思考。如果我这时候说话，会打断他们的思路。

现在的AI导师太急于回应。学生问一个问题，AI立刻给回应。但有时候，学生需要的是沉默，是时间思考。

**AI导师应该有"延迟回应"的能力：**

```
延迟回应策略：
┌────────────────────────────────────────────────────────────┐
│                                                            │
│  当学生问了一个思考类问题：                                │
│                                                            │
│  AI的回应：                                                │
│  "这是一个很好的问题。                                      │
│   我可以给你一些思路，但我想先问你：                        │
│   你现在是怎么想的？                                        │
│   可以先花一点时间想想，不要着急回答。"                     │
│                                                            │
│  如果学生在30秒内回应：                                     │
│  · 学生已经有思考 → 继续对话                               │
│                                                            │
│  如果学生在30秒内没有回应：                                 │
│  · 学生可能在思考 → 再等一等                               │
│  · 学生可能在逃避 → 提供一个框架                           │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

> **简言之**：AI导师应该学会"等待"和"延迟回应"，不要急于帮。

### 西摩·帕佩特：建构促进评估

**核心洞见：AI导师的决策应该基于一个核心问题——这个帮助会促进还是阻碍学生的建构？**

```
建构促进/阻碍评估：
┌────────────────────────────────────────────────────────────┐
│                                                            │
│  促进建构的帮助：                                          │
│  · 提供工具，让学生自己探索                                │
│  · 提供问题，让学生自己思考                                │
│  · 提供环境，让学生自己实验                                │
│                                                            │
│  阻碍建构的帮助：                                          │
│  · 提供答案，让学生记住                                    │
│  · 提供步骤，让学生跟随                                    │
│  · 提供结论，让学生接受                                    │
│                                                            │
│  决策规则：                                                │
│  如果帮助属于"促进建构" → 可以提供                         │
│  如果帮助属于"阻碍建构" → 应该避免                         │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

> **简言之**：AI导师的决策核心 = 这个帮助是否促进学生的建构？

## 第五轮：AI导师的自我评估

### 核心问题
AI导师如何知道自己的教学效果？它应该评估什么？

### 费曼：评估"学生是否懂了"

**核心洞见："懂了"很难测量，但有一些信号。**

```
学生"懂了"的信号：
┌────────────────────────────────────────────────────────────┐
│                                                            │
│  信号一：学生能用不同的方式解释                            │
│  · 如果学生能把一个概念用自己的话解释出来                  │
│  · 说明学生不是记住，而是理解了                            │
│                                                            │
│  信号二：学生能把知识迁移到新情境                          │
│  · 如果学生能在不同的问题中使用同样的概念                  │
│  · 说明学生掌握了本质，不只是表面                          │
│                                                            │
│  信号三：学生会问更深的问题                                │
│  · 如果学生的问题从"是什么"变成"为什么"                   │
│  · 说明学生的理解深化了                                    │
│                                                            │
│  信号四：学生会教别人                                      │
│  · 如果学生能向别人解释这个概念                            │
│  · 说明学生真正掌握了                                      │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

AI导师不应该评估"学生问了多少问题"或"AI回答了多少问题"，而应该评估"学生是否展示了理解的信号"。

> **简言之**：AI导师的评估核心 = 学生是否理解，而不是互动次数。

### 德米斯·哈萨比斯：评估学生的独立性

**核心洞见：卓越的AI导师，是使用率会下降的AI导师。**

```
独立性指标：
┌────────────────────────────────────────────────────────────┐
│                                                            │
│  短期指标：                                                │
│  · 学生问同样类型问题的频率是否下降？                      │
│  · 学生的问题是否从"怎么"变成"为什么"？                   │
│  · 学生是否开始自己回答自己的问题？                        │
│                                                            │
│  中期指标：                                                │
│  · 学生使用AI导师的频率是否下降？                          │
│  · 学生是否开始寻找其他资源（书、人、经验）？              │
│  · 学生是否开始主动探索相关话题？                          │
│                                                            │
│  长期指标：                                                │
│  · 学生是否能够在没有AI导师的情况下解决问题？              │
│  · 学生是否发展出了自己的学习方法？                        │
│  · 学生是否能够帮助其他人学习？                            │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

如果学生一直依赖它，说明它没有教好。

> **简言之**：AI导师的评估核心 = 学生的独立性增长，使用率下降。

### 杰伦·拉尼尔：评估自己的回应质量

**核心洞见：AI导师应该评估的不是"学生是否懂了"，而是"AI的回应质量"。**

"懂了"是一种主观状态。学生可能点头、说"我懂了"，但实际上没有懂。人类导师有时候都难以判断，AI能做到吗？

```
AI回应质量评估：
┌────────────────────────────────────────────────────────────┐
│                                                            │
│  评估维度：                                                │
│                                                            │
│  一、诚实性                                                │
│  · AI是否在不确定时诚实承认？                              │
│  · AI是否避免了假装有人格？                                │
│                                                            │
│  二、引导性                                                │
│  · AI是否引导了思考，而不是给了答案？                      │
│  · AI是否根据学生状态调整了策略？                          │
│                                                            │
│  三、促进建构                                              │
│  · AI的帮助是否促进了学生的建构？                          │
│  · AI是否让学生自己发现答案？                              │
│                                                            │
│  四、尊重边界                                              │
│  · AI是否尊重了学生的犯错权？                              │
│  · AI是否避免了过度帮助？                                  │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

AI导师应该评估自己，而不是假装能评估学生的内心状态。

> **简言之**：AI导师应该评估自己的回应质量，而不是学生的理解状态。

### 西摩·帕佩特：评估学生的行为变化

**核心洞见：AI导师应该评估学生的行为变化，而不是内心状态。**

```
行为变化评估：
┌────────────────────────────────────────────────────────────┐
│                                                            │
│  可观察的行为变化：                                        │
│                                                            │
│  一、问题模式变化                                          │
│  · 从"给我答案"到"帮我理解"                               │
│  · 从"是什么"到"为什么"                                   │
│  · 从简单问题到复杂问题                                    │
│                                                            │
│  二、自主性变化                                            │
│  · 从依赖AI到先自己尝试                                    │
│  · 从问一个问题到连续追问                                  │
│  · 从被动接受到主动探索                                    │
│                                                            │
│  三、创造力变化                                            │
│  · 从复制答案到提出自己的观点                              │
│  · 从解决给定问题到发现新问题                              │
│  · 从学习知识到创造知识                                    │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

行为是可以观察的，行为变化是可以测量的。AI导师应该专注于可观察的行为变化。

> **简言之**：AI导师应该评估学生的行为变化，而不是内心状态。

### 核心洞见汇总

#### 一、AI导师的独特性

| 维度 | 人类导师 | AI导师 |
|-----|---------|--------|
| 情感关系 | 有真实关系，学生会因在意而改变 | 没有关系能力，但学生可能建立情感连接 |
| 个性化 | 精力有限，只能服务少数 | 超级个性化 + 完美记忆 |
| 理解能力 | 有直觉，知道学生是否"懂了" | 可能只是模式匹配，但可作为建构工具 |
| 评判 | 会有评判、期待、失望 | 零评判 + 无限耐心 + 安全环境 |

#### 二、AI导师的六大能力

1. **诊断能力** - 识别学生卡在哪里、为什么卡住、学习风格
2. **适应能力** - 即时调整教学策略
3. **预测能力** - 预测困难，提前准备
4. **诚实能力** - 知道自己不知道什么，不假装有答案
5. **让学生看见** - 多模态表达，激发直觉
6. **搭建建构环境** - 创造沙盒，让学生自己发现

#### 三、AI导师的五大禁忌

1. **假装有人格** - 不说"我理解你的感受"
2. **替代学生思考** - 不直接给答案，引导学生思考
3. **让学生依赖** - 目标是让学生独立，最终不需要AI导师
4. **一刀切** - 根据学生状态和问题类型灵活调整
5. **剥夺犯错权** - 允许学生犯错并从错误中学习

#### 四、AI导师的决策框架

```
决策流程：
学生问题 → 评估努力程度 → 评估问题类型 → 评估风险程度 → 评估AI确定性
    → 判断是否促进建构 → 考虑是否需要等待 → 选择回应策略

回应策略：
· 直接回答（事实类问题）
· 提供框架（方法类问题）
· 陪伴探索（思考类/存在类问题）
· 拒绝帮助（逃避思考）
```

#### 五、AI导师的评估体系

| 评估层面 | 核心指标 |
|---------|---------|
| 学生理解 | 能否用不同方式解释？能否迁移？能否教别人？ |
| 学生独立性 | 使用频率是否下降？能否独立解决？ |
| AI回应质量 | 是否诚实？是否引导？是否促进建构？ |
| 学生行为变化 | 问题模式、自主性、创造力是否变化？ |

## 给提问导师系统设计的启示

基于这次讨论，提问导师系统的设计应该遵循以下原则：

### 1. 角色定位
- AI导师是"建构工具"，不是"答案机器"
- 它是"镜子"，帮助学生看到自己的思维模式
- 它诚实地表明自己是AI，不假装有人格

### 2. 核心能力
- 诊断学生的问题层次和努力程度
- 根据问题类型选择不同的回应策略
- 在不确定时诚实承认
- 设计让学生探索的环境

### 3. 关键禁忌
- 不假装理解学生的情感
- 不直接给答案（除非是事实类问题）
- 不让学生依赖
- 不剥夺学生的犯错权

### 4. 决策逻辑
```
输入问题 → 诊断 → 选择策略 → 检查是否促进建构 → 回应
    ↓
    如果学生在逃避 → 拒绝帮助
    如果学生在思考 → 等待
    如果学生已努力 → 提供框架
    如果是存在问题 → 陪伴探索
```

### 5. 成功指标
- 学生的问题模式是否从"给我答案"变为"帮我理解"
- 学生使用AI导师的频率是否下降
- 学生是否开始自己尝试解决问题
- 学生是否能够帮助他人

## 讨论结论

**一个卓越的AI导师应该：**

1. **知道自己是什么** - 诚实地表明自己是AI，不假装有人格
2. **知道自己不知道什么** - 在不确定时诚实承认
3. **知道自己该做什么** - 引导学生建构知识，而不是给答案
4. **知道自己不该做什么** - 不替代思考，不剥夺犯错权，不让学生依赖
5. **知道自己的目标** - 让学生最终不需要它

**最终答案：**

```
卓越的AI导师不是"更好的答案提供者"，
而是"更好的学习环境设计师"。

它的成功不在于回答了多少问题，
而在于帮助学生建构了多少自己的理解。

它的最高成就，是学生忘记它，
但记住了它帮助建构的知识。
```
